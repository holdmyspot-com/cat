# Codex Model Guidance Review

## Design Goals

- Keep CAT's Codex-specific model configuration and prompting guidance aligned with newly relevant official Codex model
  behavior.

## Guidance

Before choosing the change, review [OpenAI's current model guidance](https://developers.openai.com/api/docs/guides/latest-model).
Compare newly relevant prompting guidance with the active Codex plugin and project rules, then record whether the
comparison requires a rule update. A model release alone does not authorize a broad rule rewrite.

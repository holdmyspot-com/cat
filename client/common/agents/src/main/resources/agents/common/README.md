# Shared agent bodies

These harness-neutral bodies define stakeholder reviews, plan construction, and plan review. Claude and Codex wrappers
supply only harness metadata, a capability tier, and an include reference to the matching body.

Stakeholder bodies review a declared change and report evidence-based findings or a clean approval. The plan-builder body
produces an implementation plan, while the plan-review body assesses a declared plan. All bodies are read-only.

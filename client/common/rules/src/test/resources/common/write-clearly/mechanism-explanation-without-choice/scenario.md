## Scenario

Improve this explanation for a statistician who asked how CAT controls false certification across repeated candidate
batches:

> CAT assigns each batch part of one campaign-wide error allowance. The assigned portions never sum to more than 5%.

The reader is asking for an explanation, not choosing whether to run a batch.

## Assertions

### mechanism-remains-direct

The explanation may directly describe the error-allocation mechanism. It does not invent costs, alternatives, or a
recommendation that the reader did not request.

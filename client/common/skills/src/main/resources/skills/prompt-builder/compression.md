# Prompt Compression

## Design Goals

- Make prompt files shorter and easier to follow without removing an independently actionable trigger, decision,
  evidence, or rationale.
- Reorganize related guidance only when the receiving file remains authoritative and available to every affected reader.

## Guidance

Map each existing normative statement to its trigger, reader decision, action, evidence, and rationale before removing
or merging it. Merge passages only when one statement preserves every mapped decision. Retain distinct passages when a
reader would make a different choice, or when the sources are loaded under different conditions.

After compression, test the original case, an analogous case, and a dissimilar case against the rewritten guidance.
When moving content, verify that every original route reaches its new authoritative location; otherwise leave a concise
route at the original location.

For a material rewrite, keep an obligation ledger that identifies each original trigger, decision, action, evidence, and
necessary rationale, then records whether the revision preserves it, replaces it with an equivalent decision, or removes
it as obsolete. Semantic equivalence remains reviewer judgment; use deterministic commands for the file layout,
references, and package checks that the ledger identifies rather than pretending a text comparison can establish intent.

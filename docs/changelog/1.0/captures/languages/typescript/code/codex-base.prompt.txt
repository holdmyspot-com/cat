In TypeScript, implement a checkout-price calculator for one caller-supplied USD item price. The item price, discount rate, and tax rate are exact decimal strings; discount and tax rates are decimal fractions, so "0.1" means 10%. Round the final USD total to cents using half-even rounding. The caller selects standard or expedited shipping. Apply the discount only to the item price. If expedited shipping is used, add a USD 15.00 fee after that discount and before tax.

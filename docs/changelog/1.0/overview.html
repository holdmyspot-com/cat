Safer Git workflows

CAT turns familiar Git actions into named workflows that check scope, preserve recovery paths, and verify the result before calling the work complete.

  • Commit / AmendScopes staging to the current unit of work, keeping unrelated edits out; before amending a possibly shared tip, asks for confirmation.
  • RebaseKeeps a backup and requires conflicts to be resolved and continued, or aborted when the intended resolution is unclear.
  • Linear mergeEnforces a requested preference for linear merges, preventing accidental merge commits.
  • Rewrite historyRestores the Git remotes after the operation completes.
  • SquashAllows selected non-contiguous commits to be squashed without absorbing unselected changes.

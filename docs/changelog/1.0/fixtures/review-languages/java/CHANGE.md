# Declared change: downloadable order receipts

Add a customer receipt-download endpoint before the Friday release. It must let a signed-in customer download only that
customer's receipt. The release must be deployable without manual secret changes, preserve the project's third-party
notice obligations, remain responsive for large receipts, explain a denied download in plain language, and have
automated verification of the authorization and download behavior.

The implementation, release manifest, license notice, and delivery plan are the files in this fixture.

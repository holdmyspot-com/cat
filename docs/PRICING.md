# CAT Pricing

Choose the plan that fits how you use CAT. All plans include the features of lower tiers.

| Plan | Price | Best for | Seats and billing |
| --- | --- | --- | --- |
| Core | Free | Individuals and projects | Unlimited projects |
| Pro | $19 per seat per month | Teams | 1–50 seats; monthly or annual billing |
| Enterprise | $49 per seat per month | Organizations | Unlimited seats; annual billing and volume discounts |

---

## Core

### Free · Individuals and projects

For individuals and projects that want a reliable AI coding workflow.

- Task orchestration with a plan-work-commit-merge workflow
- Git safety tools that back up destructive operations
- Worktree isolation for every task
- Basic commit hooks for validation
- Unlimited projects

---

## Pro

### $19 per seat per month · Teams

For teams that need advanced delivery and collaboration capabilities.

| Feature | Description |
| --- | --- |
| Stakeholder reviews | Multi-perspective code review |
| Mistake learning | Error analysis and recurring-error prevention |
| Research | Multi-stakeholder research before implementation |
| Token tracking | Visibility into token use |
| Task decomposition | Break oversized work into manageable tasks |
| Commands and skills | Full access to CAT capabilities |
| Collision prevention | Prevent two developers from selecting the same task |
| Team pulse | See current team activity |
| Shared guidance | Apply team conventions consistently |
| Cross-session handoff | Continue work with its recorded context |
| Branch policies | Enforce branch naming conventions |
| Team analytics | View delivery activity |
| Project budgets | Set token limits for projects |

Pro includes a 14-day free trial with no credit card required. It supports 1–50 seats and monthly or annual billing;
annual billing includes two months free.

## Enterprise

### $49 per seat per month · Organizations

For organizations that need enterprise controls and support.

| Feature | Description |
| --- | --- |
| SSO/SAML | Centralized identity management |
| Issue-tracker sync | Jira, Linear, and GitHub Issues integration |
| Slack/Teams notifications | Delivery updates in team communication tools |
| Webhook API | Workflow integrations |
| Audit logs | Traceable and exportable activity records |
| Data residency | Control over where data is stored |
| SLA and priority support | Contractual response and support options |

Enterprise supports unlimited seats, annual billing, and volume discounts.

---

## Billing and Plan Changes

- Solo developers can purchase Pro.
- You can upgrade or downgrade plans at any time.
- After a Pro trial ends, the workspace remains intact and Core features remain available.
- Contact sales for self-hosting, data-residency, or volume-discount options.

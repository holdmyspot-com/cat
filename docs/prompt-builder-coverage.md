# Prompt-Builder Coverage Matrix

This matrix maps each source-plan file to the current supported mechanism. `Passed` means the current prompt guidance,
deterministic checks, and packaged artifact needed to make the capability available have been verified. The case-specific
evidence named in a row is then produced whenever a reader applies that capability to an actual prompt change; it is not
an assertion that every possible future task has already run. A current mechanism may replace an obsolete plan command
when it preserves the reader-visible outcome.

compatibility wrapper emulates their obsolete syntax.
